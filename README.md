# Darija Tasks

A new, small open-source task list app in Moroccan Darija.

## Features
- Add tasks, mark them complete, and delete them.
- Right-to-left interface.
- Local browser storage with a warning if saving fails.
- No external libraries or network requests in the app code.

## Run
Download the repository and open `index.html` in a modern browser. No build step is required. Persistence depends on your browser and its storage settings; local-file storage behavior can vary.

## Privacy
Tasks stay in the current browser storage. They are not synced or backed up. Clearing browser data can delete them. Do not use this prototype for sensitive information.

## Status
Initial prototype. Not yet manually tested across browsers. No established user base or impact claims.
